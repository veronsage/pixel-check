# pixel-check: распознавание AI-сгенерированных изображений

## О проекте

Разработайте на Python приложение для определения изображений, созданных искусственным интеллектом. Приложение должно принимать изображение от пользователя, анализировать его с помощью готовой предобученной ML-модели и показывать результат классификации.

Технологию пользовательского интерфейса выберите самостоятельно. Допускается веб-интерфейс или настольное приложение. Обучать или дообучать модель не требуется.

**Ориентировочное время:** 10–12 часов, включая разработку, настройку, тестирование, отчет и демонстрационное видео.

## Цель

Научиться интегрировать предобученную ML-модель в приложение, проверять входные файлы, обрабатывать ошибки и оценивать качество классификации на размеченном наборе изображений.

## Сценарий

Пользователь запускает приложение, загружает изображение и запускает анализ. Приложение проверяет файл, показывает предварительный просмотр и передает изображение модели.

После обработки пользователь видит предсказанный класс — «Реальное изображение» или «AI-сгенерированное изображение» — и оценку модели для AI-класса в процентах.

При некорректном файле или ошибке анализа приложение показывает понятное сообщение и позволяет повторить попытку.

Для выполнения задания достаточно локального запуска. Размещение приложения на сервере не требуется.

## Инструменты и материалы

- Python 3.11 или 3.12.
- Библиотека или фреймворк для интерфейса — на выбор выполняющего.
- Pillow — для чтения и проверки изображений.
- Transformers и PyTorch — для работы с моделью.
- pytest или другой инструмент автоматического тестирования.

Используйте предобученную модель [dima806/ai_vs_real_image_detection](https://huggingface.co/dima806/ai_vs_real_image_detection).

Предусмотрите запуск на CPU. При первом использовании потребуется интернет для скачивания файлов модели. Платные API не требуются.

Перед интеграцией изучите описание модели, необходимую предобработку и соответствие выходных меток классам.

## Входные данные

Приложение должно принимать одно изображение за раз.

| Параметр | Требование |
|---|---|
| Форматы | JPEG и PNG |
| Расширения | `.jpg`, `.jpeg`, `.png`, без учета регистра |
| Максимальный размер | 10 МБ — 10 × 1024 × 1024 байт |
| Содержимое | Файл должен успешно декодироваться как изображение |
| Цветовой режим | Перед передачей модели изображение приводится к RGB |

Проверяйте содержимое файла, а не только расширение. Текстовый файл, переименованный в `.jpg`, должен отклоняться.

## Функциональные требования

### 1. Загрузка и проверка изображения

- Реализуйте загрузку изображения через пользовательский интерфейс.
- Проверьте размер, расширение, фактический формат и возможность декодирования файла.
- Покажите предварительный просмотр корректного изображения.
- Не запускайте классификацию при ошибке проверки.
- При загрузке нового изображения очищайте предыдущий результат анализа.

### 2. Классификация

- Используйте указанную предобученную модель.
- Загружайте модель один раз при запуске приложения или первом анализе и повторно используйте для следующих изображений.
- Выполняйте предобработку с помощью процессора, соответствующего модели.
- Определяйте AI-класс по меткам в конфигурации модели, а не по позиции результата в списке.
- Получайте оценку AI-класса в диапазоне от 0 до 1.

Используйте единое правило классификации:

- оценка AI-класса не меньше 0,5 — «AI-сгенерированное изображение»;
- оценка AI-класса меньше 0,5 — «Реальное изображение».

### 3. Отображение результата

Показывайте предсказанный класс и оценку AI-класса в процентах. Например:

`AI-сгенерированное изображение. Оценка AI-класса: 87,3%.`

Рядом с результатом разместите пояснение:

> Результат отражает оценку модели и может быть ошибочным. Он не является доказательством происхождения изображения.

### 4. Пользовательский интерфейс

Интерфейс должен содержать:

- название и краткое описание приложения;
- элемент загрузки файла;
- предварительный просмотр изображения;
- кнопку запуска анализа;
- индикатор обработки;
- результат классификации или сообщение об ошибке.

До загрузки корректного изображения анализ должен быть недоступен.

### 5. Обработка ошибок

Предусмотрите следующие ситуации:

- неподдерживаемый формат;
- поврежденный файл или файл, который не является изображением;
- превышение допустимого размера;
- невозможность загрузить модель;
- ошибка во время классификации.

Пользователь должен получать понятное объяснение проблемы. Технические подробности записывайте в журнал или консоль.

После обрабатываемой ошибки приложение должно сохранять возможность повторной попытки.

## Проверка приложения

Добавьте автоматические тесты для следующих сценариев:

| Сценарий | Ожидаемый результат |
|---|---|
| Корректное изображение JPEG или PNG | Файл принимается и подготавливается к анализу |
| Неподдерживаемый формат | Файл отклоняется с понятной причиной |
| Поврежденное изображение или текстовый файл с расширением `.jpg` | Ошибка обрабатывается, классификация не запускается |
| Файл превышает 10 МБ | Файл отклоняется из-за превышения размера |
| Оценка AI-класса ниже, равна или выше 0,5 | Предсказанный класс соответствует установленному правилу |
| Классы расположены в ответе модели в разном порядке | Оценка AI-класса определяется по метке |

Для проверки преобразования ответа модели используйте заранее заданные ответы. Эти тесты должны запускаться без скачивания модели и подключения к интернету.

Дополнительно вручную проверьте:

- загрузку изображения и получение результата;
- замену изображения после анализа;
- повторную загрузку после ошибки;
- отображение сообщения при ошибке загрузки или выполнения модели.

## Оценка качества классификации

Используйте предоставленный автором задания набор из **40 изображений: 20 реальных и 20 AI-сгенерированных**.

Изображения размещаются в `data/test/`, правильные метки — в `data/labels.csv`, сведения об источниках — в `data/SOURCES.md`.

Проверьте весь набор. Не исключайте изображения с ошибочными предсказаниями и не подбирайте порог по результатам этой проверки.

### Результаты по изображениям

Сохраните файл `results.csv` со следующими столбцами:

| Столбец | Содержание |
|---|---|
| `filename` | Имя файла |
| `true_label` | Истинный класс: `real` или `ai` |
| `predicted_label` | Предсказанный класс: `real` или `ai` |
| `ai_score` | Оценка AI-класса от 0 до 1 |
| `correct` | Совпадает ли предсказание с истинной меткой |

### Итоговые показатели

Рассчитайте:

- **Accuracy** — долю правильных предсказаний;
- количество реальных изображений, ошибочно отнесенных к AI;
- количество AI-изображений, ошибочно отнесенных к реальным.

`Accuracy = количество правильных предсказаний / общее количество изображений`

Разберите до трех ошибочных предсказаний. Если ошибок меньше, рассмотрите все найденные. Для каждого случая укажите имя файла, истинный и предсказанный классы, оценку модели и возможные причины ошибки.

Если ошибок не оказалось, отметьте это в отчете. Объясните, почему результат на небольшом наборе не гарантирует такую же точность на других изображениях.

Фиксированный минимальный уровень accuracy не устанавливается. Важно корректно провести проверку и описать ограничения модели.
